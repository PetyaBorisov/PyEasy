# PyEasy
A library that makes coding in Python much easier
English Английский:

Hello!
I am PythonBeginner (PetyaBorisov) I am not a beginner I just made this up.
So I created this library to simplify the life of a Python programmer. Here is how to tell a person to do something.
For example:

	import(pyeasy)
	pyeasy.say("Hello, World!")
	
Output: Hello, World!
Really simple?
